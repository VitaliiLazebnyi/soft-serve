# Security Policy

## Supported versions

Soft Serve Plus is a maintained fork of [Soft Serve](https://github.com/charmbracelet/soft-serve),
which its original authors no longer maintain. Security fixes are made on `main` and shipped in
the next release. Only the latest release is supported.

Issues found in the original Soft Serve are fixed here too. Upstream releases
(`charmbracelet/soft-serve`, `charmcli/soft-serve` images) will not receive these fixes.

## Reporting a vulnerability

**Please do not report security issues in public pull requests or discussions.**

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/VitaliiLazebnyi/soft-serve-plus/security/advisories/new).

Please include:

- the affected version or commit,
- how to reproduce the issue, and
- the impact you expect (for example: who can trigger it, and what they gain).

You should get a first response within 7 days. Once a fix is released, the issue will be
published as a GitHub security advisory, crediting you unless you prefer otherwise.
